## 快速定位流程

1. **按类别找候选**（上方 8 个类别）
2. **查 `brand-craft-notes.md` 的"按产品类型推荐"** 进一步精筛
3. **读 `design-md/{品牌}/DESIGN.md` 的 `craft_notes`**（10 个标杆有详细注解）
4. **融合 2-3 个品牌的 craft_notes** → 产品专属 `craft_principles`

**无 craft_notes 的品牌**：用 `brand-craft-notes.md` §"按反 AI 味决策分类"反推 + 读 DESIGN.md tokens。
